# 📐 Aura Design System Guidelines

## 1. Color Tokens

### Brand Colors
* **Primary Blue:** `#3B82F6` — Main CTA buttons, active tab states
* **Deep Navy:** `#0F172A` — Primary backgrounds, dark surface cards
* **Emerald Green:** `#10B981` — Income indicators, success badges

### Neutral Scale
* **Background Light:** `#F8FAFC`
* **Surface Card:** `#FFFFFF`
* **Text Primary:** `#0F172A`
* **Text Secondary:** `#64748B`

---

## 2. Typography Scale

* **Display 1:** Inter Bold | 32px / 40px Line Height
* **Heading 1:** Inter SemiBold | 24px / 32px Line Height
* **Body Regular:** Inter Regular | 16px / 24px Line Height
* **Caption:** Inter Medium | 12px / 16px Line Height

---

## 3. Component Specs

### Primary Button
* **Padding:** `12px 24px`
* **Border Radius:** `12px`
* **Default State:** Background `#3B82F6`, Text `#FFFFFF`
* **Hover State:** Background `#2563EB`
* **Active State:** Scale `0.98`
