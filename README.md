# 🎨 Aura Mobile Banking & Design System

A sleek, modern mobile banking interface designed with accessibility, intuitive navigation, and micro-interactions at its core.

![Hero Banner](assets/hero-banner.png)

## 📌 Project Overview

**Aura** addresses the complexity of modern multi-currency management by streamlining everyday transactions into a single-swipe experience.

* **Target Audience:** Digital nomads, frequent travelers, multi-currency account holders
* **Role:** Lead UI/UX Designer (User Research, Wireframing, Prototyping, Visual Design, Usability Testing)
* **Tools Used:** Figma, Principle, Adobe Illustrator, HTML/CSS (Live Prototype)
* **Timeline:** 4 Weeks (Design Sprint)

---

## 🚀 Key Features & Highlights

* **1-Tap Transfers:** Optimized transaction flow reducing completion time by 40%.
* **Dynamic Dark/Light Mode:** Full contrast compliance (WCAG 2.1 AA standard).
* **Micro-Interactions:** Custom haptic-inspired UI feedback for success states.

## 🛠️ Design System Summary

* **Typography:** Inter (Primary), JetBrains Mono (Financial Data)
* **Primary Palette:** `#0F172A` (Slate Dark), `#3B82F6` (Electric Blue), `#10B981` (Success Green)
* **Spacing Scale:** 8pt Grid System
